## Design seams settled here

- `GcPreset` lives in `crates/gcl-core/src/instances/model.rs` (no new dependency edge between
  `instances` and `java`). Tokens: `default`, `serial`, `parallel`, `g1`, `zgc`,
  `zgc_generational`, `shenandoah`. `InstanceJvm.gc: GcPreset` with serde default.
- `config.jvm.gc` seeds a new instance at creation only.
- The probe is one `tokio::process::Command` (`<java> -XX:+PrintFlagsFinal -version`), not the
  `ProcessRunner` trait, which exists for loader installer processors.
- Launch re-probes the resolved Java through the cache; a manually set `java_path` carries no
  major of its own.
- Probe cache: memory per (path, mtime) plus `cache/runtimes/gc-probe.json`.
